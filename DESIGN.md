# Interface direction

<!-- impeccable:design-schema 1 -->

MZD-AIO uses a restrained light desktop interface. The app is a working utility: users should first see where to choose tweaks and where to compile USB files.

- **Surface:** soft gray canvas, white working areas, hairline dividers, and a white navigation bar.
- **Type:** macOS system sans for controls and reading; the MZD-AIO name remains the identity anchor.
- **Color:** deep navy text, muted blue for selection and the primary action, green only for successful install selection, red for removal or destructive states.
- **Structure:** quiet top navigation, clear compile action, quick selections, searchable tweak cards, and a persistent selection summary.
- **Controls:** familiar rounded buttons and inputs, obvious focus rings, and consistent 36–44 px targets where layout permits.
- **Density:** compact enough for many tweaks, with 12–16 px spacing within groups and larger gaps between work areas.
- **Motion:** only short functional hover and focus transitions; no decorative animations.
