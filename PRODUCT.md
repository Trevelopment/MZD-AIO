# Product

<!-- impeccable:product-schema 1 -->

## Platform

macOS desktop (Electron)

## Users

Mazda MZD infotainment owners preparing tweak installation or recovery files on a Mac.

## Product Purpose

MZD-AIO lets users select infotainment tweaks, configure related options, and compile files for a USB drive. It also provides autorun and recovery workflows.

## Operating Context

The desktop app runs in Electron. Users choose tweaks and compile a folder of files that they copy to a USB drive for use with a Mazda infotainment system.

## Capabilities and Constraints

- Preserve existing tweak IDs, labels, selection behavior, compile actions, and autorun/recovery workflows.
- The interface uses AngularJS, W3 CSS, Bootstrap, and local HTML/CSS assets.
- A visual redesign must not alter generated files or the vehicle installation logic.

## Brand Commitments

Keep the MZD-AIO name and Mazda-related product context. The user requested a restrained, light macOS visual direction.

## Evidence on Hand

The repository contains the application UI, tweak definitions, source assets, and packaging configuration. No vehicle test is available here.

## Product Principles

- Make tweak discovery and selection easy to scan.
- Make the path to USB compilation clear.
- Keep advanced recovery tools findable without letting them dominate the main workflow.
